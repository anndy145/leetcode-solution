# 2235. Add Two Integers

**Difficulty:** Easy
**Topic:** math  

**題目連結:** [LeetCode](https://leetcode.com/problems/add-two-integers)

## 題目意思 and 限制

輸出兩數相加

1. `-100 <= num1, num2 <= 100`


**Example**

Input: `num1 = -10, num2 = 4`

Output: `-6`

## 解法

```C++
return num1+ num2;
```

## 複雜度

**Time Complexity: $O(1)$**  
**Space Complexity: $O(1)$**
