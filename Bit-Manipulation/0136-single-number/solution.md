# 136. Single Number

**Difficulty:** Easy
**Topic:** Bit Manipulation / Array

**題目連結:** [LeetCode](https://leetcode.com/problems/single-number)

## 題目意思 and 限制

找出array中，只出現一次的數字

1. `1 <= nums.length <= 3 * 10^4`
2. `-3 * 10^4 <= nums[i] <= 3 * 10^4` 
3. 除了答案以外，不會有其他出現兩次

**Example**

Input: `[4,1,2,1,2]`

Output: `4`

## 解法
```
全部數字XOR
```

## 複雜度

**Time Complexity: $O(n)$**  
**Space Complexity: $O(1)$**
